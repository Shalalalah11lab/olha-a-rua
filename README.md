## 🎨 Design

Swiss and editorial, moving toward Brutalism: hairline rules, flat colour blocks and a dotted paper texture.

- 🔤 **Type:** Archivo, Newsreader, IBM Plex Mono
- 🟥🟦 **Colour:** paper and ink, with red `#FE5241` and blue `#3064B6` as accents that swap between light and dark themes
- 🌗 **Themes:** light and dark

The full brand identity is documented separately.

## 🛠️ How the site is built

One self-contained file, `index.html`, with the styles and scripts inside it. No build step: open it in a browser.

## 🔄 Updating the site

1. Edit `index.html` (or replace it with the new version).
2. Commit the change with a short message.
3. GitHub Pages republishes the site within a minute or two. 🚀

Larger changes go through a branch and a pull request.
